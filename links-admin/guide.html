Links Hub Admin — User Guide

A complete, plain-language guide to managing your Customer Link Hub, Marketing Signup page, and Staff Training page — no code or developer required.

📋 Overview

Links Hub is the control panel behind everything at bakudanramen.com/links/ — your "link in bio" style hub, plus the Marketing Signup page and internal Staff Training page. Everything you change here goes live immediately (or on the schedule you set) with no code, no deploys, and no developer involved.

The two halves of the system

AreaURLWho sees it
Admin (this app)/links-admin/You and your staff, logged in
Public Customer Hub/links/Anyone with the link — customers, social bio links, QR codes
Golden rule: anything you edit in the Admin and click "Save" on updates the live public page within seconds. Always double-check a change on the real public page after saving.

🔑 Logging In

  1. Go to bakudanramen.com/links-admin/
  2. Enter your email and password.
  3. You'll land on the Dashboard, with a sidebar on the left for every section of the app.
Session timeout: if you're logged out unexpectedly mid-edit, it's your login session expiring for security — just log back in. Unsaved changes in an open form are not preserved, so save frequently.

📊 Dashboard

Your at-a-glance health check when you log in. It shows:

  • Total / Live / Hidden / Scheduled / Expired / Featured button counts across all pages.
  • Views and clicks in the last 24 hours, site-wide.
  • Warnings — e.g. pages missing an SEO title, or content that looks misconfigured — so you can fix small issues before they become customer-facing problems.

📄 Pages

A "Page" is any full link hub — your main Customer Link Hub, the Staff Training page, or any campaign-specific landing page you create. Go to Pages in the sidebar to see every page you have.

Creating a new page

  1. Click + New Page.
  2. Give it a title — the URL slug is generated automatically (you can edit it).
  3. Choose a Page Type (Customer Link Hub, Staff Training, etc.) and Visibility (Public, Unlisted, Staff Only, or Password Protected).
  4. Click Create — you're taken straight into the page editor.

Draft, Publish, and Rollback

Every page has a status shown at the top: Draft or Published.

  • While a page is Draft, only you (and anyone with a Preview link) can see it — it will not appear on the live public site.
  • Click Publish Now when you're ready to make it live.
  • Every publish creates a version snapshot. Open Version History to preview or roll back to any earlier saved version if something looks wrong after publishing.
Location Scope: if you assign a page to a specific location (La Cantera / Stone Oak / Bandera) in Page Settings, a Store Manager account for that location can edit it — but Store Managers cannot edit pages that aren't assigned to their own location. See Users & Permissions.

🔘 Sections & Buttons

Inside a page, content is organized into Sections (optional group headers, like "Order Now" or "Follow Us") containing Buttons — the actual clickable links your customers see.

Adding a button

  1. Open a page → the Buttons tab.
  2. Click + Add Button.
  3. Enter a Title and choose a Destination Type — External Website, Phone, Email, Instagram, YouTube, a location's Toast order link, or an internal page.
  4. Fill in the destination (a URL, phone number, etc.) and click Add Button.

Button destination types worth knowing

TypeWhat it does
Call Store / Directions / Store Hours / Order SupportPick a location once — the phone number, map link, or hours pull automatically from that location's own record. Update the location, and every button using it updates too.
Heading / Text Block / ImageNon-clickable content blocks for adding context between buttons — no destination needed.
Internal PageLinks to another page inside your own Links Hub (e.g. from the main hub to a campaign page).

Scheduling a button

Use Start Date/Time and End Date/Time to have a button automatically appear and disappear — perfect for a limited-time promotion.

Reordering: drag buttons and sections by the handle on the left of each row to change the order customers see them in, then click Save Order.

🔍 SEO Manager

Each page has its own SEO fields, in the Page Settings tab:

  • SEO Title — overrides the default browser tab / Google search title.
  • Meta Description — the summary text shown under your link in Google search results.
  • Social Preview Image — the image shown when the link is shared on Facebook, iMessage, etc.
  • Canonical URL — advanced use only; leave blank unless you know you need it.

A live preview box shows roughly how your page will appear in Google search results as you type.

⭐ Structured Data (Rich Search Results) New

This is what lets Google show extra details — like your phone number, hours, or price range — directly in search results, without needing to touch any code or JSON.

  1. Open a page → Page Settings → scroll to Structured Data (Rich Search Results).
  2. Choose a Type: Restaurant or FAQ.
  3. For Restaurant: fill in Business Name, Cuisine, Phone, Price Range, Address, Hours, and an Image URL.
  4. For FAQ: add one or more Question / Answer pairs — great for a page answering common customer questions.
  5. Click Save Structured Data.
How it works behind the scenes: you only ever fill in plain form fields — the system builds the correct technical markup (JSON-LD) for you automatically and embeds it invisibly in the page. There's nothing to break by editing a form field.

🕒 Recurring Schedule New

For a button that should only appear on certain days or certain hours — like a Happy Hour offer — every week, without you touching it again.

  1. Edit a button → scroll to Recurring Schedule (optional).
  2. Check the days of the week it should be visible (e.g. Mon–Fri).
  3. Optionally set a From and Until time — leave both blank to show all day on the selected days.
  4. Save the button. It will now automatically show and hide itself on that recurring schedule, forever, with no further action from you.
Times are evaluated in the restaurant's local timezone (Central Time), regardless of where you're logged in from.
Combine with dates: Recurring Schedule works alongside the absolute Start/End dates — e.g. "Happy Hour, Mon–Fri 3–6pm" that also automatically stops appearing after a specific end date.

🧪 A/B Testing New

Test two versions of a button's title/subtitle against each other and see which one customers click more — no guessing, no spreadsheets.

Starting a test

  1. Edit the button you want to test → scroll to the A/B Testing section.
  2. Click Start A/B Test.
  3. Enter Variant B's title (and optional subtitle) — Variant A keeps the button's current wording.
  4. Set the Traffic Split — what percentage of visitors see Variant A vs. B (defaults to 50/50).
  5. Click Start Test.

Reading results

Edit either variant button and click View Results / End Test to see a live table of Impressions, Clicks, and Click-Through Rate (CTR) for each variant.

Ending a test

  • Keep Variant A or Keep Variant B — manually pick the winner.
  • Auto-pick Winner — automatically keeps whichever variant has the higher click-through rate.

The variant you don't keep is moved to Trash — never permanently deleted immediately, so you can always recover it if you change your mind.

How visitors are split: each visitor is assigned to Variant A or B the first time they see the button, and consistently shown the same one on every later visit from that device — so your results reflect true visitor behavior, not random flip-flopping.

📑 Templates

Save any page's full structure (sections + buttons) as a reusable template, so you don't have to rebuild a similar page from scratch every time.

  1. Open the page you want to save → click Save as Template.
  2. Give the template a name.
  3. Later, go to Templates in the sidebar → Create Page from Template to instantly generate a brand-new page with the same structure, ready to customize.

🗑️ Trash & Restore New

Deleting a page, section, or button never destroys it immediately — it moves to Trash, where you can restore it any time, or permanently delete it once you're sure.

  1. Go to Trash in the sidebar to see everything you've deleted, across every page.
  2. Click Restore to bring an item back exactly as it was.
  3. Click Permanently Delete only when you're certain you'll never need it again — this step cannot be undone.
This makes deleting things low-risk — if you delete a button by mistake, or end an A/B test and change your mind about the loser, Trash has you covered.

📣 Campaigns

Group related shortlinks together to track a specific marketing push — e.g. a seasonal promotion running across Instagram, email, and a QR code on a table tent.

  1. Go to Campaigns → New Campaign, give it a name and optional end date.
  2. Attach shortlinks to it from the UTM Builder (see below).
  3. The Campaigns list shows total clicks across every shortlink in the campaign, and its status (Active / Ended).

🔗 UTM Builder & QR Codes

Build a trackable link without typing query-string parameters by hand.

  1. Go to UTM & Shortlinks.
  2. Enter the destination URL, then Source, Medium, and Campaign name — the tool builds the full tracked URL for you and shows a live preview.
  3. Save it as a shortlink to get a short, clean URL, or download it as a QR code PNG ready to print.

📝 Forms

Build a custom form (feedback, catering inquiry, job application, etc.) that customers fill out on a real public page — no third-party form tool needed.

  1. Go to Forms → New Form, name it, and add fields (Text, Email, Phone, Textarea, Select, Radio, Checkbox, Date, or Number).
  2. Save — you'll get a public URL like bakudanramen.com/forms/?id=1 to share or link to from a button.
  3. Every submission is saved and viewable in the Admin under View Submissions for that form.
File-upload fields are not yet supported — the public form will ask the customer to email attachments instead.

🖼️ Media Library

A shared, searchable library of every image uploaded across the whole Admin — used for social preview images, button icons, and structured data images.

  1. Go to Media Library → Upload and choose a JPEG, PNG, GIF, or WEBP file (max 10 MB).
  2. Click Copy URL next to any image to paste it wherever an image field appears elsewhere in the Admin.

💬 Customer Service Notices

Show a dismissible banner at the top of the public page — for service disruptions, holiday hours, or general announcements.

  1. Go to Customer Service → New Notice.
  2. Write the message, choose a severity (Info / Warning / Critical), and optionally target it to one specific page and/or a date range.
  3. Choose whether customers can dismiss it (hide it after reading) or not.

⚙️ Automations New rule added

A small, fixed menu of safe automatic actions — not a general scripting tool. Rules only run when you explicitly click Run Automations Now; nothing runs silently in the background on a hidden timer.

RuleWhat it does
Auto-end expired campaignsWhen a campaign's end date has passed and it's still Active, sets its status to Ended.
Hide buttons when a location closesWhen a chosen location is marked Inactive, automatically hides every button pointed at it (Order, Call, Directions, etc.).
Post a closure notice when a location closes NewWhen a chosen location is marked Inactive, automatically posts a site-wide notice explaining it's temporarily closed — and automatically removes that notice once the location is reactivated.
  1. Go to Automations → New Automation.
  2. Pick a rule, fill in any required settings (e.g. which location), and save.
  3. Whenever you want the rules evaluated — e.g. right after marking a location Inactive — click Run Automations Now and check the "Last Run" summary for what happened.

📍 Locations

Your three physical locations (La Cantera, Stone Oak, Bandera) each have one record here holding their real phone number, address, map link, Toast order URL, support email, and hours. Any button using a location-derived destination type pulls from here automatically.

Marking a location Inactive is a real, live change — it can automatically hide real ordering buttons (if that Automation rule is on) and/or post a closure notice. Only toggle this for an actual closure.

👥 Users & Permissions

Go to Users to add staff accounts and control what each one can do.

RoleCan do
Super AdminEverything, everywhere.
Admin / MarketingFull content editing across all pages.
Store ManagerAssigned to one location — can only edit pages, sections, and buttons assigned to that same location. Cannot touch other locations' content.
ViewerRead-only access.
To scope a page to a Store Manager, set its Location Scope field (Page Settings tab) to match the manager's assigned location.

📈 Analytics

Go to Analytics for views, clicks, click-through rate, and a top-performing-buttons breakdown over a selectable date range — site-wide, or per individual page.

🛠️ Troubleshooting

ProblemWhat to try
A change isn't showing on the public pageConfirm the page status is Published, not Draft. Hard-refresh the public page (the public page always fetches fresh data, but your browser cache can be stale).
Logged out unexpectedlyNormal session expiry — just log back in. Save your work frequently to avoid losing an in-progress edit.
A confirmation popup seems "stuck"Some actions (like deleting or ending an A/B test) ask you to confirm first — just click OK/Cancel in that popup to continue.
Store Manager can't edit a page they should be able toCheck that the page's Location Scope matches the manager's assigned location exactly.
